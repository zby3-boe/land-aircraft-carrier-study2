## GitHub Pages 部署指南
1. 在同学本人的 GitHub 账号新建 **`Public`** 仓库（如 `eh216s-safety-analysis`）。
2. 将本目录内 `index.html`、`assets/`（含 `style.css`、`app.js`）及 `README.md` 上传至仓库根目录。
3. 在 `Settings → Pages` 中选择 `Deploy from a branch` → `main` → `/ (root)` 保存，获取链接后提交至课程飞书收集表。
